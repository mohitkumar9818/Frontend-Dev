Box-Sizing Comparison

Default (content-box)

This box uses the default box-sizing property. The width does not include padding and border, making the total box size larger than defined.

box-sizing: border-box

This box includes padding and border inside the defined width, keeping the total size fixed and easier to control in layouts.

Notice how both boxes have the same declared width and padding, but the default one appears larger due to how box-sizing works.
